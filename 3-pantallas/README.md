# Diseño de Pantallas - Salvando las Costas de Veracruz

En esta carpeta se encuentran los prototipos de las interfaces gráficas del videojuego en formato PNG:

1. **1-inicio.png:** Pantalla principal con el título del juego y menú de acceso.
2. **2-seleccion-nivel.png:** Mapa interactivo de las playas de Veracruz disponibles.
3. **3-juego-principal.png:** Vista principal de juego con el personaje, residuos, contenedores, fauna marina y HUD (tiempo y puntaje).
4. **4-pausa.png:** Menú superpuesto de pausa con opciones para reanudar, reiniciar o salir.
5. **5-resultados.png:** Pantalla de resumen al finalizar el nivel con estadísticas de limpieza y puntuación.
